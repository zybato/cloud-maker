# Cloud Maker

Решение задания по запуску и управлению виртуальными машинами на Linux-хосте.

## Реализованные пункты:
- **Базовое задание:** Запуск ВМ через QEMU (CLI).
- **Доп. задание №1:** HTTP API для управления ВМ (Flask).
- **Доп. задание №2:** Настройка `cloud-init` (передача user-data, SSH-ключей, hostname).
- **Доп. задание №9:** Ограничение ресурсов (квоты) — запрет создания ВМ при превышении лимитов (RAM/CPU).
- **Доп. задание №10:** Простой веб-интерфейс поверх API.
- **Доп. задание №11:** Скрипт автоматической проверки (`check.sh`).
- **Доп. задание №12:** Скрипт очистки (`cleanup.sh`).

> **Примечание:** На хосте (Debian внутри VirtualBox) отсутствует поддержка вложенной виртуализации (KVM), поэтому QEMU запускается в режиме программной эмуляции (`-accel tcg`). В связи с этим в квотах установлен лимит в 1 CPU во избежание Kernel panic при эмуляции многопоточности.

## Структура проекта
- `run.sh` — скрипт запуска ВМ (принимает параметры RAM и CPU).
- `api.py` — Flask-сервер для управления ВМ.
- `templates/index.html` — веб-интерфейс.
- `check.sh` — скрипт автоматической проверки (запуск ВМ и проверка SSH).
- `cleanup.sh` — скрипт очистки (удаление временных файлов и остановка QEMU).
- `user-data.yaml`, `meta-data.yaml` — конфигурация cloud-init.
- `requirements.txt` — зависимости Python.

## Как проверить решение:

### 1. Автоматическая проверка (Скрипт)
Убедитесь, что установлен `curl` (`sudo apt install curl -y`).
```bash
chmod +x check.sh cleanup.sh run.sh
./check.sh
```
## Ожидаемый результат:
 Скрипт запустит ВМ, подождет загрузки (до 8 минут) и выведет ✅ УСПЕХ: ВМ запущена, cloud-init сработал, SSH доступен!.
### 2. Проверка API и Веб-интерфейса

Установите зависимости и запустите сервер:
```
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 api.py
```
Откройте в браузере http://127.0.0.1:5000.

Нажмите «Создать ВМ» (параметры по умолчанию: 2048 MB RAM, 1 CPU). Дождитесь смены статуса на «ЗАПУЩЕНА».
Введите CPU = 4 и нажмите «Создать ВМ» — должна появиться ошибка Quota exceeded (проверка квот).
Нажмите «Остановить».
### 3. Очистка
```
./cleanup.sh
```
##Ожидаемый результат: удалены временные файлы, процесс QEMU остановлен.
